| Filename | Screen |
|----------|--------|
| `home.png` | Home / Dashboard |
| `transactions.png` | Transactions list |
| `statistics.png` | Statistics with charts |
| `accounts.png` | Accounts screen |
| `recurring.png` | Recurring payments |
| `settings.png` | Settings screen |
| `add_transaction.png` | Add transaction sheet |
| `transfer.png` | Account transfer |
| `lent.png` | Lent money tracker |
| `wishlist.png` | Wishlist |
| `categories.png` | Categories |
| `onboarding.png` | Welcome / onboarding |

## How to take screenshots

1. Run the app on a real device or emulator
2. Use `adb exec-out screencap -p > screen.png` or press the screenshot button
3. Recommended resolution: 1080×2340 (FHD+)
4. Recommended: use dark mode for consistency
